# Exa for Claude Code

Give Claude Code access to web search, page fetching, and deep research powered by [Exa](https://exa.ai).

## Install

```bash
claude plugin install exa@claude-plugins-official
```

## What's included

- **Web Search** — Search the web and retrieve relevant content.
- **Web Fetch** — Read webpages as clean markdown.
- **Exa Agent** — Multi-step research, enrichment, and structured results.
- **Agent Skills** — Bundled `search` and `exa-agent` skills for more complex workflows.

## Authentication

Web search works without an API key, with rate limits. Sign in to Exa for higher limits and Agent access.

[Documentation](https://docs.exa.ai/reference/exa-mcp) · [Get an API key](https://dashboard.exa.ai/api-keys)
